## 🌿 About the Project

**Ivory Flow** is a luxury lifestyle and interior design website created to showcase elegant furniture, timeless aesthetics, and thoughtfully curated living spaces.

The website embraces the concept of quiet luxury through a clean layout, sophisticated typography, warm visual tones, and carefully selected imagery.

It delivers an elegant browsing experience while presenting premium furniture collections and the craftsmanship behind each piece.

## ✨ Features

- **Elegant Homepage:** Minimalist hero section with luxury branding and an immersive visual experience.
- **Curated Lookbook:** A collection of interior inspiration, ceramics, textiles, furniture, and architectural details.
- **Signature Collection:** Dedicated product showcase featuring the Maren Lounge Chair.
- **Craftsmanship Process:** Highlights the four stages of creation — Source, Design, Craft, and Deliver.
- **Studio Film:** Dedicated section showcasing the creative process and studio atmosphere.
- **Contact Section:** Provides contact information and consultation opportunities.
- **Responsive Design:** Designed to deliver a visually appealing browsing experience across screen sizes.

## 🎨 Design Philosophy

The website follows a quiet luxury design approach:

- Minimalist and sophisticated layout
- Neutral and warm color palette
- Elegant typography
- High-quality lifestyle imagery
- Clean visual hierarchy
- Spacious and uncluttered sections

To explore the project locally:

1. Clone the repository:

   ```bash

   ```

2. Navigate to the project directory:

   ```bash
   cd Ivory-Flow
   ```

3. Open the project in your preferred code editor.

4. Launch the website using your preferred local development server.
